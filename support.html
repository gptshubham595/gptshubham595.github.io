Before Contacting Support

  • Confirm you are on chatgpt.com or chat.openai.com.
  • Refresh the tab and reopen the extension popup.
  • Check extension permissions are enabled in Chrome.

Common Issues

Interview does not start

  • Open a supported ChatGPT page first, then click Start Interview.
  • Make sure you are logged in to ChatGPT.
  • Disable conflicting extensions and try again.

Popup buttons not responding

  • Close and reopen the extension popup.
  • Reload the current ChatGPT tab.
  • Restart Chrome if state appears stuck.

Telemetry or score data looks wrong

  • Use Refresh in the telemetry section.
  • If needed, use Clear Stats to reset local tracking.
